## Install

Download **OscGoesPurrr-Windows.exe** below and run it. That's the whole install —
one file, no setup wizard, no Python, no separate Intiface Central.

Windows will show a blue "Windows protected your PC" box the first time,
because the exe isn't code-signed (a certificate costs a few hundred a year).
Click **More info → Run anyway**.

Already running an older version? Don't download anything — it'll offer the
update itself at launch.

- **Hear your toys come and go.** A short chime going up when a toy
  connects, and going down when one drops — switched off, out of range or
