## Install

Download **OscGoesPurrr-Windows.exe** below and run it. That's the whole install —
one file, no setup wizard, no Python, no separate Intiface Central.

Windows will show a blue "Windows protected your PC" box the first time,
because the exe isn't code-signed (a certificate costs a few hundred a year).
Click **More info → Run anyway**.

Already running an older version? Don't download anything — it'll offer the
update itself at launch.

## What's new

<!-- Replace this section before each release. Keep it short and concrete:
     what changed, and what a user would notice. -->

- **Any colour you like.** Not a green person? Settings → Appearance turns
  the whole app to the colour you pick — a few presets or a slider — while
  you watch. There's a Vibrant and a Darker look to choose from, too.
- **One Home page.** Overview and Device Routing are now a single page:
  every toy is a row, and clicking it opens its signal chains right there.
  Toys that are switched off stay listed, in grey.
- **Tell your avatar a toy is connected.** The app can set an avatar
  parameter while any toy is connected, and one per toy — for an icon on
  your avatar that lights up with the toy.
- **Toys are found by themselves.** While a toy is missing the app looks
  for it every few seconds, so the Refresh and Disconnect buttons are gone.
- **A friendlier start.** Getting started now explains its three steps —
  no Intiface to install, just Bluetooth.
- **What's new, in the app.** After an update a small window tells you
  what changed, with a button that takes you to each new thing.
