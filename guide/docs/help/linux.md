# Linux

On Linux, OscGoesPurrr is one **AppImage**.

1. Download
   [OscGoesPurrr-Linux-x86_64.AppImage](https://github.com/Blise518B/OscGoesPurrr/releases/latest/download/OscGoesPurrr-Linux-x86_64.AppImage).
2. Make it executable: `chmod +x OscGoesPurrr-Linux-x86_64.AppImage`, or
   *Allow executing* in its Properties.
3. Run it.

Bluetooth needs **BlueZ** running, which it is on most desktops. The toy
server is built in, as on Windows.

New versions install themselves: OGP swaps the AppImage file for the new one.

## What's different

- **PSVR2** is Windows only: its toolkit is. It isn't offered on Linux.
- **Show toys in SteamVR** (the toys in SteamVR's device list) is Windows
  only for now.
