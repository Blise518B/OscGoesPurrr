# Known-good version pins for the whole dependency tree.
#
# requirements.txt keeps loose `>=` ranges (what the app is compatible
# with); this file pins the exact versions a release was actually tested
# against, so `run.bat` / `build_OGP.bat` installs are reproducible and a
# surprise upstream release can't break users overnight. A pip constraints
# file never installs anything by itself — it only pins a package IF it is
# being installed — so platform-specific entries (the winrt-* stack bleak
# pulls on Windows) are ignored elsewhere, and dev/build tool pins are
# ignored for plain runtime installs.
#
# Usage:   pip install -r requirements.txt -c constraints.txt
# Refresh: venv\Scripts\python.exe -m pip freeze  (drop pip/setuptools),
#          then re-run the app + test suite before committing the bump.
#
