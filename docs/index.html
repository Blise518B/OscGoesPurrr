Smooth by design

Twitchy OSC in. Silky haptics out.

Raw avatar parameters are jittery and bursty. A stateless per-motor signal chain shapes every tick into clean motion your hardware can actually feel.

A real signal chain, per motor

Every motor runs the same pure, debounced pipeline. Nothing fires unless the target value actually changes — so the math stays cheap and the output stays smooth.

  • Depth & speed blending with per-motor tuning
  • Touch / pen / self / other contact filtering
  • Gating, smoothing & change-only debouncing

How it works

From a touch in VR to a buzz in the room

A small constellation of threads passes one signal down a clean, layered pipeline — discovered automatically, routed in real time.

Your avatar moves

VRChat emits OSC parameters — contacts, proximity, SPS — as you're touched, petted or poked.

The Eardrum vrchat_osc.py

Finds VRChat over mDNS and pulls the full parameter list via OSCQuery. No IP or port typing, ever.

The Brain parameter_store.py

One thread-safe source of truth. A version counter lets routers skip unchanged ticks instantly.

Stateless routers

Pure per-tick math reads the Brain and decides what each device should do — zones, filters, blending, smoothing.

Sealed engines

Each backend is a black box with a primitive-only facade. Add hardware by adding files, never rewiring the old ones.

Bluetooth toys

Buttplug.io · Intiface

Auto-discovery, multi-zone routing, per-motor speed-blend tuning and linear-actuator support (Solace Pro, Gravity, OSR2…). Runs a bundled engine — no separate launch needed.

0%

SteamVR trackers

Tundra · Vive · TriggerHapticPulse

Dispatches OSC values to any SteamVR device with per-tracker patterns, plus a battery broadcaster that publishes tracker battery back into VRChat.

0%

bHaptics suits

Vests · arms · feet

Translates v1 bHapticsOSC parameters into dot-mode frames for the bHaptics Player, with an antistuck timer, per-position enables and a live click-to-test dot grid.

0%

SteamVR Toy Driver

Optional virtual devices

An optional OpenVR driver that makes your toys and bHaptics positions show up as trackers in SteamVR's device strip — complete with icons and battery indicators.

0%
Built for tinkerers

Everything you'd want to tune

Deep control where you want it, sensible defaults where you don't.

🛰️

Zero-config discovery

VRChat is found over mDNS and parameters arrive via OSCQuery. Nothing to type, nothing to forward.

🧩

Multi-zone routing

Bind one motor to many OGB zones — Head, Tail, anywhere — with simple checkbox menus.

🎚️

Per-motor signal chain

Input → Depth/Speed → Combine → Gate → Smoothing → Output, with live mini-graphs for each motor.

✨

Synthetic SPS sources

Build virtual contact zones from raw receivers: proximity, an activation gate, a velocity boost and a max clamp.

👤

Avatar-bound profiles

Pin a profile to an avtr_* id and the right config loads automatically — with a global fallback.

🔎

Real-time OSC debugger

A live parameter inspector plus diagnostics: packets handled, phonebook GETs, handler exceptions and more.

Get started

Up and purring in minutes

Windows-first. Grab the prebuilt exe, or run it from source.

⚡ Prebuilt Windows exe

A standalone one-file build — no Python install required.

# grab the latest build, then
double-click OscGoesPurrr.exe

🐍 Run from source

Python 3.10+. run.bat installs dependencies for you.

pip install -r requirements.txt
python main.py # or: run.bat
